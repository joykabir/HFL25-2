
### Installation & Setup

    git clone git@github.com:joykabir/HFL25-2.git
    cd HFL25-2
    # Run the program for v01
    cd v01
    dart run bin/calculator.dart
    # Run Unit tests
    See each sub-project folder for instructions


### 🛠️ Technical Details

    Language: Dart 3.0+
    Platform: Console/Terminal application (Tested in Ubuntu 24.04)
    Dependencies: None (uses built-in dart:io library)
    Architecture: Object-oriented with single responsibility principle
